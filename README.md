# dashboard-de-vendas-com-IA-para-porsche
Dashboard criado com dados de vendas fictícios da marca de carros Porsche, utilizando a ferramenta de IA Google Antigravity

Perguntas escolhidas para gerar o dashboard:

- Quantidade de vendas sobre cada método de pagamento
- Quais são as cidades com maiores quantidades de vendas
- Top 10 de modelos de veículos vendidos

Prompts utilizados para gerar o dashboard:

- Tenho este arquivo em Excel que possui informações fictícias sobre vendas de veículos da marca Porsche. Preciso que você crie um dashboard em HTML, em um estilo Power BI, onde responda as seguintes perguntas: Indicadores de quantidade sobre cada método de pagamento, cidades com maiores quantidades de vendas e top 10 veículos vendidos por preço de venda. No topo do dashboard, quero indicadores com total de vendas e receita. Quero que o visual seja coerente com a marca Porsche, precisa ser elegante. Escolha uma paleta de cores que combine com a marca.

- Traduza as informações em inglês para português nesse dashboard

Tratamento realizado na base de dados:

- Foi realizado a remoção das colunas com os dados não modelados e os campos com data foram modelados como DATA, os de valores foram modelados como MOEDA e os dados de kilometragem como NÚMERO.

Ferramenta de IA utilizada para o desenvolvimento:

- Google Antigravity
